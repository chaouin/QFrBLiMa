# QFrMark benchmark

`qfrmark.csv` is a working benchmark export supplied by the researcher. It has 1,205 contrastive pairs and five contexts for each of 241 `feature_id` markers.

Core columns: `pair_id`, `feature_id`, `text_FI`, `text_FQ`, `marker_FI`, `marker_FQ`, `domaine`.

The dataset originated from GDT/OQLF terminology; **review licensing and redistribution permissions before making this repository public**. The upstream GDT dataset was dated 2026-01-19. Retain the citation and provenance for every retained marker. The public benchmark contains 1,205 contrastive sentence pairs covering 241 linguistic markers. All pairs are used for zero-shot evaluation.

`data/manifests/` is generated by `python scripts/prepare.py` and fixes the original and inverted A/B placements. Never change the row order of `qfrmark.csv` if trying to reproduce the paper's original seed-42 candidate assignments.

## Unified public marker IDs

All 241 markers are assigned consecutive IDs `OQLF_001` through `OQLF_241`, with five sentence pairs per marker (`_P01` through `_P05`). This replaces two historical internal prefixes, `LEX_001`–`LEX_030` and `OQLF_001`–`OQLF_211`. All markers are documented in the OQLF GDT; the old prefixes represented an internal extraction workflow, **not different sources**.

`id_mapping.csv` stores the exact old-to-new mapping for all 1,205 pairs. No FI/FQ sentence, term, domain, GDT link, concept reference or CSV ordering has changed. Existing experimental outputs must be remapped before joining to these new public IDs. You can do this with `python scripts/remap_ids.py --input legacy.csv --output migrated.csv`. The prompt and original randomization are unaffected because the dataset row ordering is unchanged.

The public CSV is a renamed-ID version of `benchmark_1205_oqlf_v2.csv`. It is **not byte-identical** to the historical file because its identifiers differ.
