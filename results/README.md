# QFrBLiMa — public results

Copy the contents of this directory into the root of `results/` in the QFrBLiMa GitHub repository.

This document describes the released LLM results. The scientific notation is **MFr (Metropolitan French)** and **QFr (Quebec French)**. For backward compatibility, legacy identifiers `FI` (0) and `FQ` (1) are retained in the dataset, code, prompts and historical results. These denote the same operational categories, not a claim that International French and Metropolitan French are linguistically synonymous.

## What is included

- `predictions/<model>/original/results.csv` — 1,205 corrected original-order judgments per model.
- `predictions/<model>/inverted/results.csv` — 1,205 corrected inverted-order judgments per model.
- `audits/<model>.json` — correction audit with both original and unified public pair IDs, retaining the historical audit payload.
- `overall_from_predictions.csv` — accuracy, consistency, robust and other counts recomputed from the 16 released CSV files.
- `id_mapping.csv` — reversible mapping between the historical and the unified public `OQLF_001`–`OQLF_241` IDs.
- `provenance.json` — hashes and migration notes.

The 100-pair historical controls, already present within the 1,205 inverted judgments, and redundant historical summary CSV files were excluded.

## Identifier migration and provenance

Predictions are directly copied from `corrected_v3.zip`, except that `pair_id` and `feature_id` were mapped to the unified public OQLF identifiers. Rows were re-ordered to match `data/qfrblima.csv`. Claude's historic CSV did not include the `valid` column; `valid=True` was added after checking the presence and admissible values of all 1,205 preferences. **No predicted preferences, rationale, candidates, correctness labels, or judgments were changed.** `judgment_id` and `original_judgment_id` retain their historical identifiers. The historical audit payloads are preserved within each public audit, alongside the corresponding new pair ID. The original archive should be retained privately for archival provenance.

The original full dataset and public version were compared row-by-row: only the two identifier fields differ. Claude historical predictions omitted a `valid` column; the public export adds `valid=True` as derived metadata after validating all explicit preferences. The public results were checked against the benchmark for exact candidate texts, A/B swaps, correctness, unique pairs and the aggregate summary of the corrected archive.

## Reproduce paper tables and graphics

From the QFrBLiMa repository root:

```bash
python scripts/analyze.py \
  --benchmark data/qfrblima.csv \
  --predictions results/predictions \
  --out results/analysis \
  --bootstrap 20000 --permutations 20000 --seed 42
```

`results/analysis/` is regenerated, not hand-edited. The original-versus-robust accuracy scatter plot (`original_vs_robust_accuracy`) and candidate-reversal outcomes (`order_robustness`) are exported separately in PNG and PDF. The analysis groups by marker for confidence intervals and statistical model comparisons, and explicitly distinguishes original-vs-inverted accuracy from A/B position preference.
